GUN CHECK

Tests every component on the AIMBOT gun, the way the game actually receives it. Press START, then work through the tiles: pull every button, push the stick all four ways, swing the gun left/right and up/down. Each tile ticks when it passes. Esc finishes. Your cursor is captured during the test, so stray clicks can't hit menu buttons.

Optional — USB serial: connect to also see raw pin states, gyro rates, joystick position and the potentiometer (it has no key, so this is the only way the game can see it). Close the Arduino Serial Monitor first; only one program can hold the port.
